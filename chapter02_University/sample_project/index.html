  • FR-03 (Dynamic Events Calendar): បង្ហាញកាលវិភាគប្រឡង និងព្រឹត្តិការណ៍នានា ជាមួយមុខងារច្រោះតាមកាលបរិច្ឆេទ។
  • FR-04 (Multi-Language Support): គាំទ្រការប្តូរភាសាខ្មែរ និងអង់គ្លេសដោយរលូនលើគ្រប់ទំព័រ។

២. តម្រូវការមិនមែនមុខងារ (Non-Functional Requirements)

  • NFR-01 (Performance): ទំព័រត្រូវផ្ទុកចប់ក្នុងរយៈពេលតិចជាង ២.០ វិនាទី (First Contentful Paint < 1.0s)។
  • NFR-02 (Mobile Responsiveness): គេហទំព័រត្រូវបង្ហាញប្លង់សមរម្យឥតខ្ចោះលើ Mobile (375px+), Tablet (768px+) និង Desktop (1200px+)។
  • NFR-03 (Accessibility - WCAG 2.1 AA): កម្រិតពណ៌ផ្ទុយ (Color Contrast) អប្បបរមា 4.5:1 និងគាំទ្រការបញ្ជាតាម Keyboard Navigation ពេញលេញ។
  • NFR-04 (Security): ដំណើរការលើ HTTPS ពិធីការ TLS 1.3 ជាមួយការការពារទម្រង់បែបបទប្រឆាំង CSRF & XSS។
