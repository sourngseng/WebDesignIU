Web Design (Year 3) មន្ទីរពិសោធន៍អនុវត្ត (Practical Lab Guide)
📄 ស្តង់ដាសៀវភៅគោល A4 (Left 2.5cm, Right 1.5cm, Top 2.5cm, Bottom 2.5cm)

សាកលវិទ្យាល័យភូមិន្ទ — មហាវិទ្យាល័យវិទ្យាសាស្ត្រកុំព្យូទ័រ

កិច្ចការអនុវត្តជាក់ស្តែងក្នុងបន្ទប់ពិសោធន៍ (Practical Lab Guide)

ម៉ូឌុល ០១ • ជំពូកទី ២៖ ការបង្កើតផែនទីគេហទំព័រសម្រាប់សាកលវិទ្យាល័យ (Create a Sitemap for a University Website)

កម្រិតសិក្សា៖ បរិញ្ញាបត្រឆ្នាំទី ៣ | រយៈពេលអនុវត្ត៖ ៣ ម៉ោង | ប្រភេទទម្រង់៖ Step-by-Step Practical Lab

គោលបំណងនៃការអនុវត្ត (Lab Objectives)

  • ១. ការវិភាគតម្រូវការអ្នកប្រើប្រាស់៖ ចេះកំណត់ក្រុមទស្សនិកជនគោលដៅ (User Personas & Stakeholders) សម្រាប់គេហទំព័រសាកលវិទ្យាល័យ។
  • ២. Card Sorting & IA៖ អនុវត្តវិធីសាស្ត្រ Card Sorting ដើម្បីចាត់ថ្នាក់ និងរៀបចំស្ថាបត្យកម្មព័ត៌មាន (Information Architecture)។
  • ៣. ការគូសប្លង់ Sitemap៖ បង្កើតផែនទីគេហទំព័រ (Visual Sitemap) តាមឋានានុក្រម ៣ កម្រិត (Level 1 Root, Level 2 Sections, Level 3 Pages) ដោយប្រើឧបករណ៍ឌីជីថល។
  • ៤. ការបំប្លែងទៅជាកូដ Semantic HTML៖ បំប្លែងប្លង់ Sitemap ទៅជាកូដរចនាសម្ព័ន្ធ Semantic HTML Navigation និងរៀបចំទីតាំង Call-to-Action (CTA)។
  • ៥. របាយការណ៍បច្ចេកទេស៖ ចងក្រងជារបាយការណ៍បច្ចេកទេស និងការពាររចនាសម្ព័ន្ធដែលខ្លួនបានបង្កើតឡើង។

សម្ភារ និងបរិស្ថានអនុវត្តដែលត្រូវការ (Required Tools & Setup)

  • Hardware & Browser: កុំព្យូទ័រភ្ជាប់អ៊ីនធឺណិត និងកម្មវិធីរុករក Google Chrome / Microsoft Edge។
  • Diagramming Tools: ឧបករណ៍គូរ Diagram (FigJam, Miro, ឬ draw.io)។
  • Code Editor: Visual Studio Code (សម្រាប់សរសេរ និងពិនិត្យកូដ HTML/CSS)។
  • Reference Project: គម្រោងគំរូ «sample_project» ក្នុង Folder ជំពូកទី ២ សម្រាប់ជាឯកសារយោង។

ការណែនាំអនុវត្តជាជំហានៗ (Step-by-Step Lab Instructions)

ជំហានទី ១៖ កំណត់ក្រុមអ្នកប្រើប្រាស់ និងតម្រូវការ (User Personas & User Goals)

គេហទំព័រសាកលវិទ្យាល័យបម្រើឱ្យក្រុមអ្នកប្រើប្រាស់ ៤ ក្រុមខុសៗគ្នា៖

  • ១. និស្សិតអនាគត (Prospective Students): ត្រូវការស្វែងរកព័ត៌មានអំពី៖ តម្លៃសិក្សា, អាហារូបករណ៍, លក្ខខណ្ឌចុះឈ្មោះ, វគ្គសិក្សា, និងប៊ូតុង Apply Now។
  • ២. និស្សិតបច្ចុប្បន្ន (Current Students): ត្រូវការស្វែងរកព័ត៌មានអំពី៖ កាលវិភាគប្រឡង, ពិន្ទុ, Student Portal Login, បណ្ណាល័យ, និងសេចក្តីជូនដំណឹង។
  • ៣. សាស្ត្រាចារ្យ និងបុគ្គលិក (Faculty & Staff): ត្រូវការស្វែងរកព័ត៌មានអំពី៖ ប្រព័ន្ធស្រាវជ្រាវ (Research Grants), វិបផតថលគ្រូ, កាលវិភាគបង្រៀន, និងបញ្ជីឈ្មោះសហការី។
  • ៤. ដៃគូ និងសាធារណជន (Partners & Public): ត្រូវការស្វែងរកព័ត៌មានអំពី៖ ប្រវត្តិសាកលវិទ្យាល័យ, ព័ត៌មានទាក់ទង, ការងារជ្រើសរើសបុគ្គលិក, និងកិច្ចសហប្រតិបត្តិការ។
