Web Design (Year 3) សៀវភៅគោល (Core Textbook)
📄 ស្តង់ដាសៀវភៅគោល A4 (Left 2.5cm, Right 1.5cm, Top 2.5cm, Bottom 2.5cm)

សាកលវិទ្យាល័យភូមិន្ទ — មហាវិទ្យាល័យវិទ្យាសាស្ត្រកុំព្យូទ័រ

មុខវិជ្ជា៖ ការរចនាគេហទំព័រ (Web Design — Bachelor Year 3)

ម៉ូឌុល ០១៖ មូលដ្ឋានគ្រឹះនៃការរចនាគេហទំព័រ និង UI/UX (Web Design Fundamentals & UI/UX)

ជំពូកទី ៤៖ ពណ៌ ពុម្ពអក្សរ និងឋានានុក្រមនៃការមើលឃើញ (Color, Typography and Visual Hierarchy)

កម្រិតសិក្សា៖ ថ្នាក់បរិញ្ញាបត្រឆ្នាំទី ៣ | រយៈពេលបង្រៀន៖ ៣ ម៉ោងសិក្សា | ស្តង់ដាឯកសារ៖ Core Textbook

គោលបំណងនៃការរៀនសូត្រ (Learning Objectives)

  • ១. ទ្រឹស្តីពណ៌ និងកង់ពណ៌៖ យល់ដឹងពីទ្រឹស្តីពណ៌ (Color Theory), កង់ពណ៌ (Color Wheel), ពណ៌បឋម (Primary), អនុវិទ្យាល័យ (Secondary), និងតតិយភូមិ (Tertiary)។
  • ២. ក្ដារលាយពណ៌ (Palette)៖ ចេះផ្សំក្បួនពណ៌ Color Schemes (Monochromatic, Analogous, Complementary, Triadic) និងអនុវត្តក្បួនសមាមាត្រ 60-30-10 Rule។
  • ៣. ស្តង់ដាពណ៌ផ្ទុយ (Contrast)៖ យល់ដឹង និងចេះវាស់កម្រិតពណ៌ផ្ទុយ (Color Contrast) ស្របតាមស្តង់ដា WCAG 2.1 AA (4.5:1)។
  • ៤. ប្រព័ន្ធពុម្ពអក្សរ (Typography)៖ យល់ដឹងពីចំណាត់ថ្នាក់ពុម្ពអក្សរ៖ Serif, Sans-serif, Monospace និងការជ្រើសរើស Web-safe fonts / Google Fonts។
  • ៥. លក្ខណៈសម្បត្តិអក្សរ៖ ក្តាប់បាននូវបច្ចេកទេស Font Size (rem, em, px), Font Weight, Line Height, Letter Spacing និង Text Alignment។
  • ៦. ឋានានុក្រម និង White Space៖ អនុវត្តគោលការណ៍ឋានានុក្រមនៃការមើលឃើញ (Visual Hierarchy) និងចន្លោះទំនេរ (White Space) ដើម្បីដឹកនាំក្រសែភ្នែកអ្នកទស្សនា។
  • ៧. មគ្គុទ្ទេសក៍រចនា (Style Guide)៖ បង្កើតមគ្គុទ្ទេសក៍រចនាស្ទីល (Website Style Guide) និងកំណត់ Design Tokens ក្នុង CSS Custom Properties។

៤.១ ដល់ ៤.៥ ទ្រឹស្តីពណ៌ និងកង់ពណ៌ (Color Theory & Color Wheel)

ទ្រឹស្តីពណ៌ (Color Theory) គឺជាវិទ្យាសាស្ត្រ និងសិល្បៈនៃការយល់ដឹងពីរបៀបដែលពណ៌មានអន្តរកម្មជាមួយគ្នា និងរបៀបដែលពណ៌ជះឥទ្ធិពលលើអារម្មណ៍ ចិត្តសាស្ត្រ និងការសម្រេចចិត្តរបស់មនុស្ស (Color Psychology)។ នៅក្នុងវិស័យឌីជីថល ពណ៌ទាំងអស់ត្រូវបានរៀបចំនៅលើ «កង់ពណ៌ (Color Wheel)»។

  • ៤. ២ ពណ៌បឋម (Primary Colors): ក្រហម (Red), ខៀវ (Blue), និងលឿង (Yellow)។ លើអេក្រង់ឌីជីថលប្រើប្រព័ន្ធ Additive RGB (Red, Green, Blue)។
  • ៤. ៣ ពណ៌អនុវិទ្យាល័យ (Secondary Colors): កើតពីការលាយពណ៌បឋមពីរស្មើគ្នា៖ បៃតង (Green), ទឹកក្រូច (Orange), និងស្វាយ (Purple)។
  • ៤. ៤ ពណ៌តតិយភូមិ (Tertiary Colors): កើតពីការលាយពណ៌បឋមជាមួយពណ៌អនុវិទ្យាល័យដែលនៅជាប់គ្នា។
  • ៤. ៥ ពណ៌ក្តៅ និងពណ៌ត្រជាក់ (Warm & Cool Colors): ពណ៌ក្តៅផ្តល់ថាមពល និងភាពរំភើប។ ពណ៌ត្រជាក់ផ្តល់នូវភាពស្ងប់ស្ងាត់ ទំនុកចិត្ត និងវិជ្ជាជីវៈ។

៤.៦ ក្បួនផ្សំពណ៌ (Color Schemes / Harmonies)

  • ១. Monochromatic (ឯកពណ៌): ប្រើប្រាស់ពណ៌តែមួយ ប៉ុន្តែមានកម្រិតខ្ចី-ចាស់ខុសៗគ្នា (Shades, Tints, Tones)។
  • ២. Analogous (ពណ៌ស្រដៀងគ្នា): ប្រើប្រាស់ពណ៌ដែលនៅជាប់គ្នាលើកង់ពណ៌ (ឧ. ខៀវ, ខៀវ-បៃតង, បៃតង)។
  • ៣. Complementary (ពណ៌ផ្ទុយគ្នា): ប្រើប្រាស់ពណ៌ពីរដែលស្ថិតនៅទល់មុខគ្នាលើកង់ពណ៌ (ឧ. ខៀវ និងទឹកក្រូច)។ កម្រិតផ្ទុយខ្ពស់ ស័ក្តិសមសម្រាប់ CTA។
  • ៤. Triadic (ពណ៌ត្រីកោណ): ប្រើប្រាស់ពណ៌ ៣ ដែលមានចម្ងាយស្មើគ្នានៅលើកង់ពណ៌ជាទម្រង់ត្រីកោណសម័ង្ស។
  • ៥. Split-Complementary: ប្រើពណ៌គោលមួយ រួមជាមួយពណ៌ពីរដែលនៅសងខាងនៃពណ៌ផ្ទុយរបស់វា។

៤.៧ ក្ដារលាយពណ៌នៃគេហទំព័រ (Website Color Palette)

អនុវត្តតាម «ក្បួនសមាមាត្រ 60 - 30 - 10 (The 60-30-10 Rule)»៖

  • ៦០% ពណ៌ចម្បង (Dominant Color): ពណ៌ផ្ទៃខាងក្រោយ (Background / Canvas) ដូចជា #F8FAFC។
  • ៣០% ពណ៌បន្ទាប់បន្សំ (Secondary Color): ពណ៌រចនាសម្ព័ន្ធលើ Header, Cards, Footers (#0F172A)។
  • ១០% ពណ៌លេចធ្លោ (Accent Color): ពណ៌សង្កត់សំឡេងលើប៊ូតុង Primary CTA (#F59E0B)។

៤.៨ កម្រិតពណ៌ផ្ទុយ និងស្តង់ដាពិភពលោក (Color Contrast & WCAG 2.1)

ស្តង់ដា WCAG 2.1 កម្រិត AA តម្រូវឱ្យ៖

  • ១. អត្ថបទធម្មតា (Normal Text < 18pt): Contrast Ratio យ៉ាងតិច 4.5:1
  • ២. អត្ថបទធំ (Large Text ≥ 18pt): Contrast Ratio យ៉ាងតិច 3.0:1
  • ៣. ធាតុ UI និងប៊ូតុង: Contrast Ratio យ៉ាងតិច 3.0:1

៤.៩ ដល់ ៤.១៥ ប្រព័ន្ធពុម្ពអក្សរ (Web Typography Fundamentals)

  • ៤. ៩ ប្រភេទពុម្ពអក្សរ: Serif (មានជើង), Sans-serif (គ្មានជើង ដូចជា Khmer OS Siemreap ងាយអានលើអេក្រង់), Monospace (កូដកម្មវិធី)។
  • ៤. ១០ Font Family: Web-Safe Fonts vs Google Fonts (Kantumruy Pro, Moul)។
  • ៤. ១១ Font Size: ណែនាំឱ្យប្រើប្រាស់ relative units (rem) ដោយ 1rem = 16px។
  • ៤. ១២ Font Weight: 400 (Regular), 600 (Semi-bold), 700 (Bold)។
  • ៤. ១៣ Line Height: សម្រាប់ Body Text គួរស្ថិតនៅចន្លោះ 1.5 ដល់ 1.8។
  • ៤. ១៤ Letter Spacing: បន្ថែម 0.5px ដល់ 1.5px សម្រាប់អក្សរធំ (ALL CAPS)។
  • ៤. ១៥ Text Alignment: Left Alignment គឺងាយអានបំផុត ជៀសវាង Justify លើគេហទំព័រ។

៤.១៦ ឋានានុក្រមនៃការមើលឃើញ (Visual Hierarchy)

ដឹកនាំក្រសែភ្នែកអ្នកទស្សនាតាមរយៈ៖ ទំហំ (Size), កម្រាស់ (Weight), ពណ៌ (Color & Contrast), និង ទីតាំងលំហ (Spatial Position)។

៤.១៧ ចន្លោះទំនេរ (White Space / Negative Space)

  • Macro White Space: ចន្លោះធំៗរវាង Sections និង Layout Containers។
  • Micro White Space: ចន្លោះតូចៗរវាងបន្ទាត់អក្សរ (Line-height) និង Padding ក្នុងប៊ូតុង។

៤.១៨ ភាពស៊ីសង្វាក់គ្នានៃការរចនា និង Design Tokens

/* កូដ Design Tokens ក្នុង CSS Custom Properties */
:root {
  --color-primary: #0284c7;
  --color-secondary: #0f172a;
  --color-accent: #f59e0b;
  --font-h1: 2.0rem;
  --font-body: 1.0rem;
  --space-md: 16px;
}

សេចក្តីសង្ខេបមេរៀន (Chapter Summary)

ជំពូកទី ៤ នេះបានបញ្ចប់ Module 01 យ៉ាងពេញលេញ ដោយផ្តល់នូវឧបករណ៍សោភ័ណភាព និងស្ថាបត្យកម្មនៃការមើលឃើញ។ ការជ្រើសរើសពណ៌តាមក្បួន 60-30-10 Rule និងការធានា Contrast Ratio តាមស្តង់ដា WCAG 2.1 ជួយឱ្យគេហទំព័រមានទាំងភាពស្រស់ស្អាត និងលទ្ធភាពទទួលបាន (Accessibility) ខ្ពស់។

សំណួរត្រួតពិនិត្យការយល់ដឹង (Review & Discussion Questions)

  1. ចូរពន្យល់ពីក្បួនសមាមាត្រពណ៌ 60 - 30 - 10 នៅក្នុងការរចនាគេហទំព័រ។
  2. តើស្តង់ដា WCAG 2.1 កម្រិត AA តម្រូវឱ្យមានកម្រិតពណ៌ផ្ទុយ (Contrast Ratio) ប៉ុន្មានសម្រាប់ Normal Text និង Large Text?
  3. ចូរប្រៀបធៀបភាពខុសគ្នារវាងពុម្ពអក្សរ Serif និង Sans-serif។
  4. ហេតុអ្វីបានជាគេណែនាំឱ្យប្រើប្រាស់ឯកតា relative units (rem) ជំនួសឱ្យ pixels (px)?
  5. ចូរពន្យល់ពីភាពខុសគ្នារវាង Macro White Space និង Micro White Space។
