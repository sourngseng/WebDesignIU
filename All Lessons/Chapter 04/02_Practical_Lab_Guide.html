គោលបំណងនៃការអនុវត្ត (Lab Objectives)

  • ១. ក្ដារលាយពណ៌៖ បង្កើតក្ដារលាយពណ៌អាជីពតាមក្បួន 60-30-10 Rule (Primary, Secondary, Accent, Neutral, Semantics)។
  • ២. WCAG Contrast Audit៖ ធ្វើតេស្ត និងផ្ទៀងផ្ទាត់កម្រិតពណ៌ផ្ទុយ Color Contrast ឱ្យជាប់ស្តង់ដា WCAG 2.1 AA (4.5:1)។
  • ៣. ជញ្ជីងខ្នាត Typography Scale៖ កំណត់ប្រព័ន្ធពុម្ពអក្សរ Modular Typography Scale (H1 ដល់ H4, Body, Small) ជាឯកតា rem។
  • ៤. ប្រព័ន្ធ White Space៖ រៀបចំប្រព័ន្ធចន្លោះទំនេរ Spacing System (8px Grid: 4px, 8px, 16px, 24px, 32px)។
  • ៥. ការសរសេរកូដ CSS Tokens៖ បំប្លែង Style Guide ទាំងមូលទៅជា Design Tokens ក្នុងកូដ CSS Custom Properties (:root)។

ការណែនាំអនុវត្តជាជំហានៗ (Step-by-Step Lab Instructions)

ជំហានទី ១៖ កំណត់អត្តសញ្ញាណ និងក្ដារលាយពណ៌ (Brand Palette Selection)

  • Primary Color (30%): ពណ៌តំណាងស្ថាប័ន (Sky Blue #0284c7)។
  • Secondary Color: ពណ៌រចនាសម្ព័ន្ធ និងអត្ថបទក្បាល (Deep Navy #0f172a)។
  • Accent Color (10%): ពណ៌ប៊ូតុង Primary CTA (Amber Gold #f59e0b)។
  • Dominant Neutral (60%): ពណ៌ផ្ទៃខាងក្រោយ (Off-white #f8fafc)។

ជំហានទី ២៖ ធ្វើតេស្តកម្រិតពណ៌ផ្ទុយតាម WCAG 2.1 Contrast Checker

បើកឯកសារ sample_project/index.html រួចផ្ទៀងផ្ទាត់កម្រិត Contrast Ratio៖

  • Body Text (#1e293b លើ #f8fafc) ត្រូវតែ ≥ 4.5:1 (PASS AA)
  • CTA Button (#0f172a លើ #f59e0b) ត្រូវតែ ≥ 3.0:1 (PASS AA)

ជំហានទី ៣៖ បង្កើតជញ្ជីងខ្នាតពុម្ពអក្សរ (Modular Typography Scale)

  • H1: 2.0rem (32px) / Bold / Line Height: 1.3
  • H2: 1.5rem (24px) / Semi-bold / Line Height: 1.4
  • H3: 1.25rem (20px) / Semi-bold / Line Height: 1.4
  • Body: 1.0rem (16px) / Regular / Line Height: 1.7
  • Small: 0.75rem (12px) / Regular / Line Height: 1.5

ជំហានទី ៤៖ បង្កើតប្រព័ន្ធ Design Tokens ក្នុង CSS (:root)

:root {
  --color-primary: #0284c7;
  --color-secondary: #0f172a;
  --color-accent: #f59e0b;
  --font-h1: 2.0rem;
  --font-body: 1.0rem;
  --space-unit: 8px;
}

តារាងពិន្ទុវាយតម្លៃការអនុវត្ត (Evaluation Rubric — 100 Points)

  • ១. គុណភាពក្ដារលាយពណ៌ (២៥ ពិន្ទុ)៖ ជ្រើសរើសក្ដារលាយពណ៌ត្រឹមត្រូវតាមក្បួន 60-30-10 និងមានសោភ័ណភាពស្រស់ស្អាត។
