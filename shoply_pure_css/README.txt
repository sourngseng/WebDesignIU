SOURNG ACADEMY — PURE HTML + CSS3 E-COMMERCE DEMO
==========================================

No Bootstrap. No external CSS framework. No JavaScript.

Files:
- index.html     Homepage / product listing
- product.html   Product detail
- cart.html      Shopping cart
- checkout.html  Checkout form
- success.html   Order success page
- style.css      Original responsive CSS3

Run:
1. Extract the ZIP.
2. Keep all files in the same folder.
3. Open index.html in a browser.

Responsive layout:
- Desktop: four-column product grid and two-column checkout layouts.
- Tablet: two-column product grid.
- Mobile: single-column detail/checkout layout, compact product cards, and pure CSS mobile navigation (hamburger dropdown + quick cart touch target).

Important:
This is a static front-end demonstration. Links navigate between pages and the checkout form submits to success.html. Cart contents are sample/static; no dynamic cart state, database, or real payment processing is implemented. The checkout form uses native HTML validation. No JavaScript is included.
